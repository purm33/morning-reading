# 독서 아침활동 (초5·6)

2026년 11월 13일 ~ 12월 31일 평일(성탄절 제외) 34일, 하루 한 권씩 줄거리 요약을 읽고 생각 질문 3개에 답하는 아침활동입니다.

- 첫 화면(학급 홈페이지): `index.html` — 홈 · 독서활동 · 자리바꾸기 탭 (`nav.js`)
- 독서활동 학생 화면: `reading.html` (번호로 접속, 1~12번 · 51~63번)
- 자리바꾸기: `seats.html` (짝/모둠, 남녀 짝·같은 성끼리·남녀 골고루, 섞이면 안 되는 사이, 앞자리, 고정, 기록 — 이 기기 브라우저에 저장)
- 교사 화면: `teacher.html` (날짜별·질문별 답 보기, 누적 현황, 엑셀 내려받기)
- 책·질문 내용: `books.js`
- 제출 기록: 파이어베이스 `morning-activities` 프로젝트의 `reading/날짜/번호`
- `database.rules.json`: 기존 아침활동(morning) + 독서(reading) 규칙을 합친 것. 파이어베이스 콘솔 → Realtime Database → 규칙에 통째로 붙여 넣고 게시
